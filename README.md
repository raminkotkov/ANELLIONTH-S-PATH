# Путь Анеллиона

Играть: https://raminkotkov.github.io/ANELLIONTH-S-PATH/

Готовая браузерная версия. Профиль и прогресс хранятся только в текущем браузере. В настройках можно сохранить прогресс в файл и восстановить его. Пароль не требуется; сетевых аккаунтов и облачной синхронизации нет.

Этот репозиторий содержит только готовые файлы игрока. Сервер, база данных, рабочие исходники, тесты и инструменты разработки сюда не входят.
